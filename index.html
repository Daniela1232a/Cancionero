Cómo publicar gratis en GitHub Pages

Este proyecto está estructurado en un único archivo HTML independiente. Para tener tu propio cancionero online disponible desde el celular o tablet de toda tu banda:

  1. Crea un nuevo repositorio en tu cuenta de GitHub (por ejemplo: cancionero-iglesia o my-songbook) como Público.
  2. Guarda este código como un archivo llamado estrictamente index.html.
  3. Sube el archivo index.html a la rama principal (main).
  4. En tu repositorio en GitHub, ve a Settings > Pages.
  5. En Branch, selecciona main y la carpeta / (root), luego pulsa Save.
🎉 En 1 minuto tendrás tu enlace público (ej. https://tu-usuario.github.io/cancionero) accesible desde cualquier navegador sin pagar nada. Tus canciones se guardan automáticamente en tu dispositivo.
