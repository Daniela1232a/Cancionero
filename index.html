Sincronización en la Nube con GitHub

Conecta este cancionero directamente a tu repositorio para guardar y actualizar tu lista de alabanzas en la nube (archivo songs.json).

Tu token se guarda únicamente en este navegador y viaja seguro mediante HTTPS hacia la API de GitHub.

🎵 Formato de Cifrado (ChordPro)

Escribe la letra con total normalidad e introduce el acorde entre corchetes [Acorde] justo antes de la letra o sílaba donde debe sonar.

// Ejemplo directo:

//[G]No hay Dios que pueda hacer las [D]obras

como las que [A]haces tú// [D]

  • Secciones: Escribe # Coro, # Estrofa 1 o # Puente para resaltar títulos de sección.
  • Acordes al aire: Si un acorde va al final sin letra debajo, ponlo con un espacio: tú// [D].
  • Transposición: Cambia de tono en tiempo real (+1 / -1 semitono) sin alterar tu texto original.
